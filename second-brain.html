Intrinsic Safety Selection

  • Only classify an instrument as intrinsically safe when the device is in a hazardous area and an explosion-proof option cannot be selected.
  • Do not select the Rosemount I5 certification option. It is only intrinsically safe and should not be used for these cases.
  • Prefer E5 or K5 when explosion-proof certifications are available so the instrument does not need to be classified as intrinsically safe.

Acopian Redundant Power Supplies

  • Acopian redundant power supplies are used for applicable systems.
  • Set outputs to 26 VDC instead of 24 VDC to account for voltage drop.
  • Acopian offers linear regulated and switching regulated redundant power supplies.
  • We use linear regulated units for signal purity and stability, accepting larger size and lower efficiency.
  • Model breakdown: B16497 is the redundant case that houses two W16497A internal power supplies.
  • Typical spec notes: 26 VDC output, 46 amp, with amp meters, wall mounted, switching regulated.
  • Joe Chism has spare W16497A units. A GMN is being investigated for these units.
