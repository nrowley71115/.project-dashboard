\## Intrinsically Safe

We only classify an instrument as I.S. if the instrument is in a hazardous area and an explosion proof option can't be selected. Rosemount instruments have an I5 certification option for only I.S. and we should never select this. E5 and K5 have explosion proof certifications which will not require us to classify as I.S.
